# Hydra-ACRL screenshots

Place owner-approved captures here as `gazebo.png`, `rviz.png` or `dashboard.png`. Capture Gazebo Small House, the live Hydra graph in RViz or the four-pane launcher from an actual run. Review simulator asset rights and crop terminal paths, user names, private data and credentials before staging. Include the source run and a short description when linking a capture from the main README.

The release currently includes this guide. Screenshot files are Git-ignored by default. Stage only a reviewed capture by its exact path, for example `git add -f -- docs/screenshots/gazebo.png`.
