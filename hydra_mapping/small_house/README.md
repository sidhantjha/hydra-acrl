# AWS Small House assets

This directory contains the 64 model directories referenced by the Hydra-ACRL Small House world, from [AWS RoboMaker Small House at ff9631c](https://github.com/aws-robotics/aws-robomaker-small-house-world/tree/ff9631ca6d1db9c1ba656498151464b5ab74aafe). The accompanying [AWS license](LICENSE) is copied from that revision.

Hydra-ACRL applied the [ShoeRack inertia typo correction](../patches/aws-shoerack.patch) and updated the Collada portrait paths to resolve the original pinned JPEGs stored alongside their materials. The packaged world derivative and its attribution are in the [bringup package](../tb3_ws/src/tb3_hydra_bringup/).
